# LingoMate – Android-Prototyp

Dies ist der erste mobile LingoMate-Prototyp mit statischem Companion und bebilderten französischen Vokabelkarten.

## Am einfachsten auf Android

Wenn du nur ein Smartphone verwenden möchtest, lies **BUILD_ON_GITHUB.md**. Das Projekt enthält bereits einen GitHub-Actions-Workflow, der automatisch eine installierbare `LingoMate.apk` erzeugt. Auf dem Smartphone werden weder npm noch Android Studio benötigt.

## Lokale Entwicklung (optional)

```bash
npm install
npx expo start
```

## Funktionsstand

- statischer Companion
- Home-Dashboard
- Freies Gespräch (Demo-Antworten oder eigener API-Endpunkt)
- französische Text-to-Speech-Ausgabe
- bebilderte Vokabelkarten nach Reisen, Essen & Trinken, Stadt & Verkehr und Kleidung
- Platzhalter für Grammatik, Rollenspiele, Kultur und Fortschritt
